# Contributing to Image Downloader

Thank you for your interest in improving Image Downloader! Contributions, bug reports, and suggestions are welcome.

## How to Contribute

1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make Your Changes**: Keep modifications focused and clean.
4. **Test the Extension**:
   - Reload the unpacked extension at `chrome://extensions`.
   - Test on various websites (standard blogs, infinite-scroll image feeds, e-commerce sites).
5. **Commit and Push**:
   ```bash
   git commit -m "Add feature: description of change"
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request**: Provide a concise summary of what was changed and why.

## Reporting Issues

When reporting an issue, please include:
- The browser and version you are using.
- The URL of the page where the issue occurred (if public).
- Expected vs actual behavior.
- Any error logs shown in the DevTools console (`Inspect popup`).
